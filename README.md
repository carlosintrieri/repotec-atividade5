# 🚀 Projeto Full Stack

Bem-vindo ao projeto! Este é um guia rápido para configurar e executar a aplicação.

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter instalado:
- Node.js (versão 14 ou superior)
- npm (geralmente vem com o Node.js)

## 🎯 Como Executar

Para rodar este projeto, você precisará de **dois terminais** abertos simultaneamente - um para o backend e outro para o frontend.

### 🔧 Terminal 1 - Backend

```bash
cd src/backend
node server.js
```

O servidor backend estará rodando e pronto para receber requisições!

### 🎨 Terminal 2 - Frontend

```bash
npm start
```

> **📦 Nota:** Se você encontrar algum erro relacionado ao `react-scripts`, instale-o primeiro:
> ```bash
> npm install react-scripts
> ```

## ✅ Tudo Pronto!

Depois de executar ambos os comandos, a aplicação estará rodando:
- **Backend**: Verifique o console para ver a porta em que está rodando
- **Frontend**: Geralmente abre automaticamente no navegador em `http://localhost:8080`

## 💡 Dicas

- Mantenha ambos os terminais abertos enquanto trabalha
- Se precisar parar a aplicação, use `Ctrl + C` em cada terminal
- Certifique-se de que as dependências estão instaladas rodando `npm install` em ambas as pastas, se necessário
